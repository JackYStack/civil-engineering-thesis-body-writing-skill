# Core Workflow

1. Select one primary task mode from `manifest.yaml` and `references/meta/task-mode-manifest.md`.
2. Load only the fragments matching the task axes: mode, section, source, and operation.
3. Use `references/index.md` to open deeper guides only when the task requires them.
4. Build evidence, terminology, and reader-question checks before major drafting or Word edits.
5. Draft, revise, audit, or edit according to the selected output contract.
6. Before returning thesis body prose, remove meta-discourse that explains what adjacent chapters “solve,” why their tasks differ, or why content is not repeated; preserve only direct technical cross-references.
7. Remove generic applicability, extrapolation, normative-check, high-fidelity-review, missing-record, and future-validation disclaimers from ordinary method/results body prose; retain such items only in internal notes or a user-requested limitations section.
8. For a DOCX edit confined to one section, visually inspect only the pages occupied by that section and validate unaffected content structurally.
9. Validate file-producing or skill-maintenance work with the scripts listed in `manifest.yaml`.
