# Core Output Format

- For formal tasks, follow the matching contract in `references/meta/output-contracts.md`.
- For small local edits, lead with the revised text and list only material risks.
- For citation tasks, include sentence-level support notes and full-text status.
- For `.docx` tasks, report output path, original preservation, edited scope, and validation.
- For object/data work, distinguish scientific/source, numeric, structure and visual checks; name unresolved definitions and checks not performed.
- For skill-maintenance tasks, report changed scope, validation actually run, capability exclusions, and commit/publish state. Do not imply an uncommitted change was published.
