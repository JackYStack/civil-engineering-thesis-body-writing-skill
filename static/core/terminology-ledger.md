# Terminology Ledger

Use this lightweight rule before multi-section, bilingual, SCI, formula-heavy, GUI/code-linked, or Word-revision tasks. Open `references/architecture/terminology-ledger.md` for the full ledger.

- One concept should keep one canonical term.
- Do not vary technical terms for style.
- Lock symbols, abbreviations, captions, formula variables, and GUI/code labels.
- Flag ambiguous terms instead of silently choosing when the meaning affects claims.
