# Section: machine-learning

Report data source, features, outputs, preprocessing, models, hyperparameters, metrics, comparison, and interpretability. In ordinary method/results prose, stop at evidence-backed findings; keep generic extrapolation warnings, normative-check disclaimers, and future-validation advice in internal notes unless the user requests a dedicated limitations section.

Retain dataset coverage, leakage controls, held-out evaluation conditions, and material failure cases needed to interpret performance. These are technical disclosure, not generic defensive prose; SHAP attribution does not establish physical causation.

Use `references/workflows/research-integrity-and-reproducibility.md` for grouping, preprocessing/tuning isolation, fair comparison, metric definitions and uncertainty. For numerical tables/plots or reported errors also load `references/workflows/equation-figure-table-integrity.md`.
