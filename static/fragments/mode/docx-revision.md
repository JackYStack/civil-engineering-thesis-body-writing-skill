# Mode: docx-revision

Use for Word deliverables. First select `create`, `convert`, or `revise`.

- For a new DOCX or Markdown-to-DOCX conversion, load `references/workflows/docx-creation-and-formatting.md`, establish the formatting contract, and treat the institution/journal template as authoritative.
- For an existing Word file, preserve the original, edit a new copy, and load `references/workflows/docx-ooxml-editing.md`.
- For formulas, captions, numbering, fields, tracked changes, and comments, preserve native Word objects or report any degraded representation.
- Validate package/XML integrity and representative content. For a local single-section revision, visually inspect only the rendered pages occupied by the changed section; use full-document visual review for multi-section/global-layout changes or an explicit final-submission audit.
